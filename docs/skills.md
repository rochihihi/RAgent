# RAgent 项目技能

打开项目会话，点击标题旁的“技能”。选择 SKILL.md 或粘贴完整内容，点击“导入技能”；勾选要启用的技能，点击“保存启用项”。任务运行或等待权限时不能修改启用项。

文件保存到项目 `.agents/skills/<name>/SKILL.md`，可随 Git 分享。也可手动放入此位置，再打开技能界面刷新。每个技能目录名必须与 name 一致。启用项按会话保存，重启后保留。取消勾选即停用，不删除文件。

示例：

```markdown
---
name: code-review
description: 代码审查流程
---
逐项检查变更的正确性、可维护性和测试覆盖。
```

启用后发送“审查最近的代码变更”，检查技能是否按要求执行。这里只提供流程指导；文件和命令操作仍经过已有权限检查。

当前支持范围：

- 单文件指令技能，name 和 description 使用单行元数据；尚非完整 YAML 解析器。
- name 使用小写字母、数字、下划线、短横线，最长 64 字符。
- 单个及启用内容合计上限 12000 字符，每会话最多启用 10 项。
- 同名导入拒绝覆盖；需要更新时手动编辑原文件，下次请求读取新内容。
- 显式勾选启用，不支持 `$name` 自动激活、语义自动选择、GitHub/ZIP 安装、个人目录或脚本资源包导入。
- 技能不增加权限，不会仅因导入而执行脚本。只导入可信内容。
- 技能说明在上下文压缩和请求重试时保留，较长技能会占用上下文预算。

验证：`python -m pytest tests/test_studio_skills.py -q`。
